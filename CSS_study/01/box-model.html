一、盒模型的组成

从内到外：content（内容，蓝色）→ padding（内边距，绿色间隙）→ border（边框，黑色）→ margin（外边距，橙色区域，本身透明）

content 内容区 200 × 100

二、两种盒模型对比（width 都设为 200px）

标准盒模型 content-box
实际占位 = 200 + 40 + 20 = 260px

content-box
宽度会“撑大”

怪异盒模型 border-box
实际占位 = 200px（padding、border 往里挤）

border-box
宽度始终 200px

重置样式推荐：* { box-sizing: border-box; } —— 设置 width 后加 padding/border 不会把盒子撑大，布局更直观。

三、外边距折叠（margin 塌陷）

上下相邻块级元素的 margin 会重叠并取最大值：下盒 margin-bottom: 30px， 上盒 margin-top: 20px，实际间距只有 30px（左右 margin 不折叠）。

我是上盒子，margin-bottom: 30px
我是下盒子，margin-top: 20px
